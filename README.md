# HW 4.3 - Busiest Airports & Monte Carlo Integration Analysis

## About This Project
This project analyzes passenger traffic trends across six international
airports (ATL, DEN, DXB, FRA, LHR, PKX) from 2020 to 2024, exploring recovery
patterns following the COVID-19 pandemic. It also applies Monte Carlo
integration using a Weibull distribution, showing how estimate
accuracy improves with larger sample sizes.
